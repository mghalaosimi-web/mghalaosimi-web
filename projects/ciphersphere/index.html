CipherSphere

تطبيق سطح مكتب تعليمي للتشفير التطبيقي، يعرض خطوات الخوارزميات والتحويلات الرياضية بصرياً ضمن واجهة PyQt6.

01 — نظرة عامة

نظرة عامة

المشكلة

يصعب على المتعلم تتبع التحويلات الداخلية لخوارزميات التشفير وفهم أثر كل خطوة عند الاكتفاء بإدخال النص وعرض الناتج.

الهدف

توفير مختبر تفاعلي يعرض خطوات التشفير والتحليل بصورة مرئية لأغراض التعلم والتجربة.

الفئة المستفيدة

طلاب التشفير وأمن المعلومات والمتعلمون الذين يحتاجون إلى رؤية خطوات الخوارزميات.

القيمة

تحويل الخوارزميات إلى خطوات قابلة للملاحظة مع واجهة رسومية ومحركات منفصلة للخوارزميات.

02 — الميزات الموثقة

الميزات الموثقة

  • واجهة رسومية تفاعلية باستخدام PyQt6.
  • وحدات منفصلة لخوارزميات كلاسيكية وحديثة والتجزئة والترميز.
  • تتبع مرئي لخطوات AES وDES ومختبر نظرية الأعداد وRSA.
  • ملفات بناء وتجهيز نسخة تنفيذية لنظام Windows.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • Python 3.10+
  • PyQt6
  • Cryptographic algorithms
  • Windows executable build tooling

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

واجهة PyQt6 رئيسية تتصل بموزع/متحكم للخوارزميات، ثم وحدات Python مستقلة للتشفير الكلاسيكي والمتماثل ونظرية الأعداد والتجزئة والترميز.
