01 — نظرة عامة

نظرة عامة

المشكلة

تشتت المعرفة والمستندات وأدوات الذكاء الاصطناعي، وصعوبة ضبط الوصول ومراجعة مصادر الإجابات.

الهدف

توفير منصة محلية/ذاتية التشغيل لربط المستندات بالاسترجاع والبحث وإدارة النماذج والمستخدمين.

الفئة المستفيدة

الفرق التي تحتاج إلى مساعد معرفي ثنائي اللغة وبحث منظم في المستندات.

القيمة

جمع المساعد المعرفي وإدارة المستندات والنماذج والصلاحيات ضمن منصة واحدة.

02 — الميزات الموثقة

الميزات الموثقة

  • مساعد ذكاء اصطناعي ثنائي اللغة.
  • مساحة عمل للبحث في المستندات واسترجاع المعرفة.
  • إدارة النماذج والتحكم في إعداداتها.
  • واجهات إدارة ومستخدمين مع ضوابط وصول.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • Python 3.11–3.13
  • FastAPI
  • RAG
  • SQLite
  • Docker
  • pytest

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

تطبيق Python/FastAPI مع وحدات API وخدمات أساسية وطبقات للمعرفة والمستندات وإدارة النماذج. توثيق المستودع يتناول RAG والاستدلال المحلي ومراجعات الاستقرار والأمان.
