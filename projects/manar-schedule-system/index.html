Al-Manar Schedule Systems

عائلة أنظمة أكاديمية لإدارة الجداول الجامعية والبوابات والصلاحيات وتعديلات الجدول والتنبيهات، ممثلة في مستودعين مرتبطين.

01 — نظرة عامة

نظرة عامة

المشكلة

إدارة الجداول والتغييرات الأكاديمية والطلاب والمحاضرين عبر قنوات منفصلة تؤدي إلى صعوبة نشر التحديثات ومتابعتها.

الهدف

توفير بوابات مترابطة للطلاب والإدارة مع محرك جداول وإدارة صلاحيات وإشعارات وسجلات تشغيل.

الفئة المستفيدة

الطلاب والمحاضرون والإداريون ومشرفو الأنظمة الأكاديمية.

القيمة

تنظيم الجدول الأكاديمي وتعديله مركزياً مع فصل واجهات الأدوار ودعم التنبيهات.

02 — الميزات الموثقة

الميزات الموثقة

  • بوابة لعرض الجداول الأسبوعية ومعلومات المقررات والمحاضرين والقاعات.
  • إدارة الجداول والتعديلات الفورية من واجهات الإدارة.
  • أدوار وصلاحيات منفصلة للطلاب والإدارة والمشرف الأعلى.
  • إشعارات مجدولة وسجلات للتنبيهات.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • React 18
  • Vite
  • Node.js
  • Express
  • Prisma
  • PostgreSQL
  • JWT
  • CAPTCHA
  • Cron

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

واجهة React/Vite تتصل ببوابة خلفية Express على Node.js. يستخدم المشروع Prisma للوصول إلى PostgreSQL، مع middleware للمصادقة وRBAC وجدولة المهام.
