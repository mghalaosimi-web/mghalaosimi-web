Manar Schedule System

نظام لإدارة الجداول الجامعية وشؤون الطلاب والبوابات الأكاديمية، مخصص لكلية الجامعة اليمنية وفق سجل المشروع، ويتضمن مستودعه تطويرات موسعة للهوية والجلسات وتطبيق Flutter مع مزامنة محلية.

01 — نظرة عامة

نظرة عامة

المشكلة

تحتاج إدارة الجداول والطلاب والعمليات الأكاديمية إلى بوابات مترابطة، وإدارة هوية موحدة، واستمرارية أفضل عند ضعف الاتصال.

الهدف

تطوير نسخة متكاملة من نظام الجداول تشمل واجهات الويب، طبقات الهوية والجلسات، أدوات الإدارة والإصدار، وتطبيق جوال يدعم التخزين والمزامنة المحلية.

الفئة المستفيدة

طلاب ومحاضرو وإداريو كلية الجامعة اليمنية وفق سجل المشروع؛ لا يذكر README اسم المؤسسة صراحةً.

القيمة

يجمع بين إدارة الجدول والبوابات الأكاديمية وميزات الهوية والمزامنة وتوزيع إصدارات تطبيق الجوال.

02 — الميزات الموثقة

الميزات الموثقة

  • بوابات ويب للطلاب والإدارة والمحاضرين، مع إدارة الجداول والتعديلات الأكاديمية.
  • طبقات موسعة للمصادقة والهوية والجلسات، مع أدوات ترحيل وفحص وتدقيق للبيانات.
  • تطبيق جوال Flutter بهيكل ميزات مستقل وخدمات اتصال ومزامنة وتخزين محلي.
  • إدارة إصدار التطبيق وملف APK منشور ضمن أصول المستودع؛ وجود الملف لا يثبت اعتماده أو توزيعه للمستخدمين.
