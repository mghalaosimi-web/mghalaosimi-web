01 — نظرة عامة

نظرة عامة

المشكلة

الحاجة إلى مرجع رقمي موحد يعرض الهوية المهنية والأعمال البرمجية بمعلومات قابلة للتحقق بدلاً من تشتتها عبر المنصات.

الهدف

تقديم موقع عربي وإنجليزي سريع ومتجاوب، مع صفحات مستقلة للمشاريع وبيانات منظمة وتهيئة لمحركات البحث.

الفئة المستفيدة

الجهات المهنية وفرق التوظيف والعملاء والمطورون والمهتمون بأعمال M.GH.AL.

القيمة

جمع الهوية والسيرة والمهارات والشهادات والمشاريع في مرجع رسمي واحد مع دعم RTL وLTR.

02 — الميزات الموثقة

الميزات الموثقة

  • محتوى عربي RTL وإنجليزي LTR مع صفحات منفصلة.
  • محفظة مشاريع تعتمد سجل JSON موحداً وتوليد صفحات تفاصيل ثنائية اللغة.
  • بيانات SEO وOpen Graph وTwitter Cards وStructured Data وSitemap.
  • دعم PWA عبر manifest وService Worker وصفحة offline.
  • فحوصات TypeScript وإمكانية الوصول وجودة المحتوى والصفحات.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • HTML5
  • CSS3
  • JavaScript
  • TypeScript 7
  • Node.js 22+
  • Vercel

04 — المعمارية

المعمارية

موقع ثابت يعتمد صفحات HTML وأصول CSS/JavaScript وسجل JSON للمشاريع. ينفذ Node.js مرحلة بناء تولّد صفحات المشاريع وتنسخ مخرجات النشر إلى public، مع تجميع ملفات TypeScript الخاصة بسكربتات المتصفح.

05 — الصور

الصور

لا توجد لقطات شاشة مستقلة مضافة؛ الغلاف Artwork توضيحي.

06 — الحالة والمصادر

الحالة والمصادر

تطوير نشط

  • README.md يعرّف المستودع كموقع شخصي ثنائي اللغة.
  • package.json يثبت أوامر build وtypecheck وquality وتوليد صفحات المشاريع.
  • بنية المستودع تتضمن صفحات HTML وملفات TypeScript وPWA manifest وService Worker.
  • الموقع نفسه هو المنصة الحاضنة للمحفظة؛ لا تُعرض هذه الصفحة كلقطة شاشة للتطبيق.
  • لم يُضف رابط Demo منفصل؛ عنوان الموقع هو المرجع الرسمي نفسه.
