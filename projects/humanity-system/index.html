01 — نظرة عامة

نظرة عامة

المشكلة

الحاجة إلى تنظيم السجلات والعمليات المؤسسية ضمن نظام موحد بدلاً من توزيعها بين ملفات وأدوات منفصلة.

الهدف

توفير واجهة إدارية موحدة وقابلة للتثبيت، مع طبقة خلفية منظمة وصلاحيات وجلسات على مستوى الخادم وواجهات API.

الفئة المستفيدة

فريق المؤسسة والمستخدمون المخولون بإدارة السجلات والعمليات.

القيمة

تجميع العمليات المؤسسية في تجربة عربية متجاوبة، مع مسار ويب وتطبيق Android مبني على Capacitor.

02 — الميزات الموثقة

الميزات الموثقة

  • واجهة عربية RTL متجاوبة للعمليات والسجلات المؤسسية.
  • جلسات آمنة وصلاحيات تُطبّق على الخادم وواجهات API.
  • إعداد PWA للتثبيت على الأجهزة.
  • مشروع Android باستخدام Capacitor مع إعدادات وأصول التطبيق.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • Next.js
  • TypeScript
  • Prisma
  • SQLite (development configuration)
  • PWA
  • Capacitor
  • Android

مستخرجة من README وبنية المستودع؛ لا تعني أن كل خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

تطبيق Next.js مع TypeScript وواجهات API وطبقة Prisma. يصف README إعداد SQLite للتطوير، ويوثق PostgreSQL كخيار إنتاجي موصى به؛ لم يُثبت من الملفات التي تمت مراجعتها اتصال إنتاجي محدد.
