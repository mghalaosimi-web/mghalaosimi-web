Al-Manar Schedule System

نظام إدارة الجداول الأكاديمية المخصص لكلية المنار الجامعية، وفق سجل المشروع واسم المستودع، مع بوابة للطلاب ولوحات إدارة ومصادقة وصلاحيات وتنبيهات مجدولة.

01 — نظرة عامة

نظرة عامة

المشكلة

توزع الجداول والتغييرات الأكاديمية وإدارة الطلاب والتنبيهات بين أدوات منفصلة يصعّب متابعة التحديثات وإيصالها.

الهدف

توفير نظام أكاديمي مركزي لعرض الجداول وإدارة التعديلات والطلاب والصلاحيات والتنبيهات عبر بوابات مخصصة للأدوار.

الفئة المستفيدة

طلاب ومحاضرو وإداريو كلية المنار الجامعية.

القيمة

إدارة الجداول الأسبوعية والتعديلات والتنبيهات من نظام موحد مع فصل صلاحيات الطالب والإدارة والمشرف الأعلى.

02 — الميزات الموثقة

الميزات الموثقة

  • محرك جداول أسبوعية يعرض المقررات والمحاضرين والقاعات وتوزيع الحصص.
  • تعديلات إدارية على الجداول مع تنبيهات مرتبطة بالتغييرات.
  • بوابات وصلاحيات منفصلة للطلاب والإداريين والمشرف الأعلى.
  • مصادقة JWT مع تحقق CAPTCHA، وملخصات تنبيه مجدولة عبر WhatsApp/Cron وفق README.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • React 18
  • Vite
  • Node.js
  • Express
  • Prisma 7
  • PostgreSQL
  • JWT
  • CAPTCHA
  • WhatsApp integration
  • Cron
  • Capacitor

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

واجهة React/Vite تتصل بخادم Express على Node.js، ويستخدم Prisma للوصول إلى PostgreSQL. يضم الخادم middleware للمصادقة والتحقق وRBAC وخدمة جدولة للتنبيهات.
