01 — نظرة عامة

نظرة عامة

المشكلة

تجزؤ دورة إنتاج المحتوى بين أدوات الكتابة والتصميم ولوحات النشر، مع تكرار إعداد النسخ المناسبة لكل منصة.

الهدف

توحيد دورة المحتوى من الفكرة إلى المراجعة والتصميم والجدولة والنشر مع سجل تدقيق وتكاملات رسمية.

الفئة المستفيدة

صنّاع المحتوى وأصحاب العلامات والحسابات الاجتماعية الذين يديرون محتوى عربياً متعدد المنصات.

القيمة

توليد نسخ متعددة من فكرة واحدة، وإنشاء صور عربية RTL، وإدارة الموافقات والتكاملات من مساحة عمل واحدة.

02 — الميزات الموثقة

الميزات الموثقة

  • مركز قيادة للمساعد الذكي وجدولة المحتوى.
  • استوديو صور عربي يعتمد SVG وSharp لتوليد صور فعلية.
  • مسودات ومراجعة وموافقة ونسخ مهيأة للمنصات.
  • تكاملات موثقة مع Meta Graph API وTikTok Content Posting API.
  • سجل تدقيق وإخفاء بيانات الاعتماد واستبعاد WhatsApp على مستوى المعمارية.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • Next.js 16.4.3
  • TypeScript
  • Google Gemini 2.5 Flash
  • Prisma 7.10.1
  • Tailwind CSS 4
  • Vitest
  • Sharp
  • SVG

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

تطبيق Next.js/TypeScript مع طبقة Prisma، ومحوّل Gemini، ومحرك توليد صور عبر Sharp وSVG، وموصلات نشر للمنصات الرسمية. يذكر README PostgreSQL مع مسار fallback محلي.
