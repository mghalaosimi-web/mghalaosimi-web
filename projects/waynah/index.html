01 — نظرة عامة

نظرة عامة

المشكلة

المعلومات المحلية والعناوين غير الرسمية متفرقة، وقد تختلف كتابة الأسماء ومواقع الأماكن ومصادر بياناتها، مما يصعّب الوصول إلى معلومة مكانية موثوقة.

الهدف

بناء بنية موحدة لاكتشاف الأماكن والخدمات في اليمن، مع هرمية جغرافية ومحرك بحث مكاني ونموذج ثقة وتحقق قابل للتدقيق.

الفئة المستفيدة

الأفراد والباحثون عن الأماكن، والأنشطة المحلية، ومقدمو الخدمات، والجهات التي تحتاج إلى بيانات مكانية منظمة.

القيمة

تحويل سؤال «وينه؟» إلى اكتشاف مكاني منظم يوضح المكان وسياقه وكيفية الوصول إليه ومدى موثوقية بياناته.

02 — الميزات الموثقة

الميزات الموثقة

  • هرمية جغرافية من المحافظة والمديرية والعزلة إلى التجمعات والمعالم والأماكن.
  • بحث نصي ومكاني مع مراعاة اختلافات كتابة الأسماء العربية.
  • حالات ثقة وتحقق وسجل تدقيق للتغييرات والبلاغات.
  • نماذج للأماكن والأنشطة والفروع والخدمات والكتالوج.

03 — التقنيات المستخدمة

التقنيات المستخدمة

  • Next.js 16.3
  • Hono 4.13
  • TypeScript 5.8
  • PostgreSQL 17
  • PostGIS 3.3
  • Prisma 6.4
  • Turborepo

تعكس القائمة ما ظهر في README وبنية المستودع؛ ولا تعني أن كل تكامل أو خدمة إنتاجية اختُبرت حياً.

04 — ملخص المعمارية

ملخص المعمارية

Monorepo يضم تطبيقات الويب وواجهات API وخدمات المجال. توثيق المشروع يوضح تدفقاً من واجهات Next.js إلى بوابة Hono ثم خدمات المجال وطبقة Prisma وقاعدة PostgreSQL/PostGIS.
