# Certificate Source Files Inbox

Upload the original certificate assets for the M.GH.AL credentials audit into this folder.

## What to upload
- All 51 certificate images.
- The corresponding original PDF files.
- Keep the original filenames whenever possible.

## Matching rules
- Do not rename files to guessed certificate names.
- If an image and PDF belong to the same certificate, matching filenames are helpful but not required.
- Include all files together in this folder; the audit will match them by visible certificate title, issuer, holder name, issue date, credential ID, and verification URL.
- Files that cannot be matched confidently will be listed for clarification rather than assigned by guesswork.

## Important
This is a staging folder for source assets. Files here are not yet approved for publication or linked to the live credentials page. After the audit, confirmed assets will be moved/copied into the appropriate production asset paths and linked to the correct credential records.
