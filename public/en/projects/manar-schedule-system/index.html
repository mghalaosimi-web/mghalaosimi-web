Manar Schedule System

A university scheduling and student-operations system assigned to Yemen University College in the M.GH.AL project registry, with expanded identity/session work and a Flutter mobile app with local synchronization.

Public repository — documented development iteration; live operation not verifiedIndependent public repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

Academic scheduling and student operations need connected portals, consistent identity management, and better continuity when connectivity is limited.

Goal

Develop a fuller scheduling-system iteration spanning web portals, identity and session layers, administration and release tooling, and a mobile app with local storage and synchronization.

Audience

Students, lecturers and administrators at Yemen University College according to the project registry; the repository README itself does not explicitly name the institution.

Value

Combines timetable management and academic portals with identity, synchronization, and mobile-app release capabilities.

02 — DOCUMENTED FEATURES

Documented features

  • Web portals for students, administrators and lecturers, including timetable management and academic overrides.
  • Expanded authentication, identity and session layers, with data migration, inspection and audit tooling.
  • A Flutter mobile app with feature-based structure, connectivity services, synchronization and local storage.
  • An app-release management interface and an APK asset are present in the repository; their presence does not prove public adoption or distribution.

04 — ARCHITECTURE SUMMARY

Architecture summary

A React/Vite and Node/Express application using Prisma/PostgreSQL, alongside a separate Flutter mobile app. The repository also contains database-baseline, identity/session migration, and release-management tooling.
