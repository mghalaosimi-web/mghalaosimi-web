Manar Schedule System

A university scheduling and student-operations system assigned to Yemen University College in the M.GH.AL project registry, with expanded identity/session work and a Flutter mobile app with local synchronization.

Independent repository — documented development iterationOne public repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

Managing timetables, academic changes, students and lecturers across separate channels makes updates difficult to distribute and track.

Goal

Provide connected student and administration portals with a schedule engine, role management, notifications and operational records.

Audience

University and college students, lecturers and academic administrators.

Value

Centralize academic scheduling and overrides while separating role-specific portals and notification workflows.

02 — DOCUMENTED FEATURES

Documented features

  • Web portals for students, administrators and lecturers, including academic timetable operations.
  • Expanded authentication, identity and session layers with data migration, inspection and audit tooling.
  • A Flutter mobile app with feature-based structure, connectivity services, synchronization and local storage.
  • A release-management interface and an APK asset are present; their presence does not prove public adoption or distribution.

04 — ARCHITECTURE SUMMARY

Architecture summary

A React/Vite and Node/Express application using Prisma/PostgreSQL, alongside a separate Flutter mobile app. The repository also contains database-baseline, identity/session migration, audit and release-management tooling.
