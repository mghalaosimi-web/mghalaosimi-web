Al-Manar Schedule System

An academic scheduling system for Al-Manar University College, with weekly timetables, student and admin portals, role controls and scheduled notifications. The README names it the Al-Manar University Schedule & Academic Management System.

Independent repository — documented implementationOne public repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

Managing timetables, academic changes, students and lecturers across separate channels makes updates difficult to distribute and track.

Goal

Provide connected student and administration portals with a schedule engine, role management, notifications and operational records.

Audience

Students, lecturers and administrators at Al-Manar University College.

Value

Centralize academic scheduling and overrides while separating role-specific portals and notification workflows.

02 — DOCUMENTED FEATURES

Documented features

  • A weekly timetable engine displaying courses, lecturers, rooms and class allocations.
  • Administrative timetable overrides with notifications tied to schedule changes.
  • Separate portals and permissions for students, administrators and super administrators.
  • JWT authentication with CAPTCHA verification and scheduled WhatsApp/Cron notification digests, as documented in the README.

This list reflects the README and repository structure; it does not mean every integration or production service was tested live.

04 — ARCHITECTURE SUMMARY

Architecture summary

A React/Vite frontend connects to a Node.js/Express server using Prisma with PostgreSQL. The backend includes authentication, verification and RBAC middleware plus scheduled notification services.
