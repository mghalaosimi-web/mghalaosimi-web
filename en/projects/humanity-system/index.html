PROJECT PROFILE · Institutional web system

Humanity System | Humanity Brings Us Together

An institutional web system for records and operational workflows, with an Arabic RTL interface, PWA support and Android packaging.

Active development — private repositoryPrivate repository; source link is not exposed publicly
Private source — link not published

01 — OVERVIEW

Overview

Problem

The need to organize institutional records and workflows in one system rather than across disconnected files and tools.

Goal

Provide a unified installable administrative interface with a structured backend, server-side access controls, sessions and APIs.

Audience

Institutional teams and authorized users who manage records and operations.

Value

Bring institutional workflows into a responsive Arabic experience with a web path and a Capacitor-based Android shell.

02 — DOCUMENTED FEATURES

Documented features

  • Responsive Arabic RTL interface for institutional records and workflows.
  • Server-enforced permissions and session-based access across API routes.
  • PWA configuration for installable web access.
  • Capacitor Android project with application configuration and assets.

03 — TECHNOLOGY STACK

Technology stack

  • Next.js 16.2.4
  • React 19.2.4
  • TypeScript
  • Prisma 6.19.0
  • Capacitor 8.3.1
  • Zod 4.3.6
  • SimpleWebAuthn 13.1.1
  • SQLite (local development configuration)

This list reflects the README and repository structure; it does not mean every integration or production service was tested live.

04 — ARCHITECTURE SUMMARY

Architecture summary

A Next.js and TypeScript application with API routes and a Prisma data layer. The README describes SQLite for local development and documents PostgreSQL as a recommended production option; a specific production connection was not established by the reviewed files.
