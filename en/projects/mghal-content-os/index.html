M.GH.AL Content Studio

An Arabic content operating system combining planning, AI generation, image design, draft workflows and publishing through official platform APIs.

Active development — documented interfaces and implementationPublic repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

Content production is fragmented across writing, design and publishing tools, with repeated manual adaptation for each platform.

Goal

Unify the content lifecycle from idea through review, design, scheduling and publishing, with audit logs and official integrations.

Audience

Creators and brand owners managing Arabic content across multiple social platforms.

Value

Generate platform-specific variants from one idea, render Arabic RTL visuals and manage approvals and integrations in one workspace.

02 — DOCUMENTED FEATURES

Documented features

  • AI-assisted command center and content scheduling.
  • Arabic image studio using SVG and Sharp to render image assets.
  • Draft, review and approval workflows with platform-specific variants.
  • Documented integrations with Meta Graph API and TikTok Content Posting API.
  • Audit logs, masked credentials and an explicit WhatsApp exclusion in the architecture.

03 — TECHNOLOGY STACK

Technology stack

  • Next.js 16.4.3
  • TypeScript
  • Google Gemini 2.5 Flash
  • Prisma 7.10.1
  • Tailwind CSS 4
  • Vitest
  • Sharp
  • SVG

This list reflects the README and repository structure; it does not mean every integration or production service was tested live.

04 — ARCHITECTURE SUMMARY

Architecture summary

A Next.js/TypeScript application with Prisma, a Gemini adapter, a Sharp/SVG image renderer and publishing connectors for official platform APIs. The README documents PostgreSQL and a local fallback path.
