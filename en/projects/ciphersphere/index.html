CipherSphere

An educational applied-cryptography desktop application that visualizes algorithm steps and mathematical transformations in a PyQt6 interface.

Educational application prototypePublic repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

Learners can struggle to understand internal cryptographic transformations when tools show only input and output.

Goal

Provide an interactive lab that exposes cryptographic steps visually for learning and experimentation.

Audience

Cryptography and information-security students who need to inspect algorithm steps.

Value

Make algorithm behavior inspectable through a GUI and separated cipher modules.

02 — DOCUMENTED FEATURES

Documented features

  • Interactive PyQt6 graphical interface.
  • Separate modules for classical and modern ciphers, hashing and encoding.
  • Visual step tracking for AES and DES, plus number-theory and RSA tooling.
  • Build tooling for a Windows executable package.

03 — TECHNOLOGY STACK

Technology stack

  • Python 3.10+
  • PyQt6
  • Cryptographic algorithms
  • Windows executable build tooling

Derived from README and repository structure; not every production integration has been live-tested.

04 — ARCHITECTURE SUMMARY

Architecture summary

A PyQt6 main window connects to a cipher dispatcher/controller, which routes operations to independent Python modules for classical and symmetric ciphers, number theory, hashing and encoding.
