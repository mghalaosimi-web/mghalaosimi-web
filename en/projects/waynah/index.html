PROJECT PROFILE · Geospatial web platform

WAYNAH | وَيْنَه؟

A Yemen-focused geographic discovery platform that connects places with administrative context, local information and explicit verification states.

Active development — documented implementation phasesPublic repository

01 — OVERVIEW

Overview

Problem

Local information and informal addresses are fragmented; place names, locations and source records can conflict, making reliable discovery difficult.

Goal

Build a unified discovery infrastructure for places and services in Yemen, combining geographic hierarchy, spatial search and auditable trust and verification.

Audience

People looking for places, local businesses, service providers and organizations that need structured geographic data.

Value

Turn “Where is it?” into structured discovery that explains a place, its context, how to reach it and how trustworthy its data is.

02 — DOCUMENTED FEATURES

Documented features

  • Geographic hierarchy from governorates and districts to settlements, landmarks and places.
  • Text and spatial discovery designed to handle Arabic name variations.
  • Trust and verification states with an audit trail for changes and reports.
  • Domain models for places, businesses, branches, services and catalogues.

Technology stack

This list reflects the README and repository structure; it does not mean every integration or production service was tested live.

04 — ARCHITECTURE SUMMARY

Architecture summary

A monorepo containing web applications, API surfaces and domain services. Project documentation describes a flow from Next.js interfaces through a Hono API gateway and domain services to Prisma and PostgreSQL/PostGIS.
