M.GH.AL Official Website

A bilingual professional website presenting the M.GH.AL identity, profile, credentials and verified software portfolio through a static, indexable architecture.

Active developmentPublic repository
Public GitHub repository ↗README & documentation ↗

01 — OVERVIEW

Overview

Problem

The need for a single verifiable digital reference for professional identity and software work instead of fragmented profiles across platforms.

Goal

Deliver a responsive Arabic and English website with standalone project pages, structured content and search-engine metadata.

Audience

Professional contacts, hiring teams, clients, developers and visitors interested in M.GH.AL work.

Value

Unify identity, résumé, skills, credentials and projects in one official reference with RTL and LTR support.

02 — DOCUMENTED FEATURES

Documented features

  • Arabic RTL and English LTR content with separate pages.
  • A project portfolio powered by a unified JSON catalogue and generated bilingual detail pages.
  • SEO metadata, Open Graph, Twitter Cards, structured data and sitemap.
  • PWA support through a manifest, service worker and offline page.
  • TypeScript, accessibility, content-quality and page validation checks.

03 — TECHNOLOGY STACK

Technology stack

  • HTML5
  • CSS3
  • JavaScript
  • TypeScript 7
  • Node.js 22+
  • Vercel

This list reflects the README and repository structure; it does not mean every integration or production service was tested live.

04 — ARCHITECTURE SUMMARY

Architecture summary

A static site built from HTML pages, CSS/JavaScript assets and a JSON project catalogue. A Node.js build step generates project pages and prepares the public output directory, while TypeScript compiles browser scripts.
